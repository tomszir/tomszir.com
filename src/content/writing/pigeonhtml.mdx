In [Pigeon](/writing/pigeon) it's 2003, so the web inside it should look like 2003 too. I could have drawn a retro theme over modern pages. Instead, a Pigeonweb page can only use what a browser understood back then: HTML 4.01 Transitional and CSS 2.1. I call it PigeonHTML.

<ExplorerPage page="home" caption="Pigeon Home, the start page Explorer opens. A real PigeonHTML page, in the frame Pigeon shows it in." />

Tables for layout, `<font>` for type, a `<marquee>` and a "best viewed 1024x768" button, all of it allowed. One rule does two jobs here. Pages look their age because nothing newer exists, and they're safe to show because scripts never existed in the first place.

## What's allowed

Every element meets one of three fates. The groups below cover every element in Pigeon's own lists.

### Tags dropped, text kept

Text survives almost everything: an element Pigeon doesn't know loses its tags and keeps what's inside. Only the things that aren't text go whole, like scripts, pictures and SVG.

Explorer sanitizes every page before it shows it, even the ones that come with Pigeon. Those also have a test of their own: each must pass the validator, lose nothing to the sanitizer, fit the budget and only link to pages that exist. A script that got past the sanitizer would still have the three layers around the frame to get through, and none of them lets one run.

## Fonts from the era

A page can ask for the fonts everyone had in 2003. Pigeon ships two free clones and draws each name with one of them, so these are the faces a page gets.

<Fonts />

A name that isn't on either list is drawn in Tahoma. Images are GIF, JPEG or PNG, animated GIFs too, drawn with square pixels. And `<blink>` blinks again, unless you've asked your system for less motion.

## Not there yet

- **Your own pages.** For now the only pages are the ones that come with Pigeon. Hosting your own, mirrored by friends, is next.
- **Widgets.** A visitor counter, a guestbook and a webring, written as comments like `<!--#include widget="counter" -->` and drawn by Explorer, so pages never need a script. The sanitizer drops them for now.
- **Framesets and forms.** Each frame is another page to load and lock down, so they wait for hosted pages. Forms lose their tags and keep their text.

These pages can sit a few pixels off from what Pigeon shows. Explorer writes a page into its frame itself, and here each page is a file of its own. Their marquees also stand still here if you've asked for less motion, which Pigeon doesn't do yet. The pages, their checks and the frame's rules are Pigeon's own.
